02Route 3D — Multi-Criteria 3D Mobility Studio v0.1.0

02Route 3D is an elite QGIS plugin designed for multi-criteria 3D route planning, kinematic simulation, and hardware-accelerated 3D urban visualization directly inside QGIS.

1. Key Capabilities

  • Embedded 60 FPS WebGL 3D Studio: Real-time hardware-accelerated 3D terrain visualization, LOD1 building massing, volumetric trees, and dynamic sun/shadow simulation.
  • 15 Specialized Mobility Profiles: Adult, Senior, Stroller, Child, Wheelchair ADA, Bicycle, Mountain Bike, E-Scooter, Car, Van, Heavy Truck, Paramedic, Sightseer, and Night Walk.
  • Multi-Criteria Decision Analysis (AHP): Pairwise comparison matrix with Saaty consistency validation (CR < 0.10) for slope, thermal LST, and tree canopy weights.
  • Traveling Salesperson (TSP) Optimizer: 2-Opt local search optimization to reorder multi-stop journeys.
  • Turn-by-Turn Navigational Cue Sheet: Tabular instructions with slope warnings, elevation deltas, and CSV/HTML export.
  • Origin-Destination (OD) 3D Cost Matrix: High-speed N x M pairwise travel-time, distance, and calorie matrix calculator.
